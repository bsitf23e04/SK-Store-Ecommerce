# E-Commerce Storefront 🛍️

A responsive mini e-commerce storefront built as the **Capstone Project** for the Neurofive Solutions internship.

## ✨ Features

* Product listing using Fake Store API
* Search and category filtering
* Product detail view
* Add/remove products from cart
* Update cart quantities and live total
* Cart persistence using `localStorage`
* Checkout summary page
* Responsive design
* Reusable UI components
* Toasts, modals, animations & transitions

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Fake Store API
* LocalStorage
* Git & GitHub

## 🚀 Run Locally

Clone the repository and open `index.html` with **Live Server**.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```
